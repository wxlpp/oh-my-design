# 公开 static 成员的 MainActor 隔离豁免表（#307）
#
# 本文件是 `scripts/mainactor-static-ratchet.sh` 的**唯一**期望集合：脚本从
# symbol graph 里筛出「公开 / open 的 static 型成员，且声明片段里带 `@MainActor`」，
# 与本表做**双向差集**——多一条、少一条都判红。
#
# ⇒ 新加一个 `public static let` 到本包自己声明的类型上时：
#   · 它默认被 `.defaultIsolation(MainActor.self)` 卷进 MainActor ⇒ 脚本判红；
#   · 处置是**给它加 `nonisolated`**（或给 enclosing type 加），而不是往本表里补一行。
#   · 确实修不掉（初始化表达式本身是 MainActor 隔离的）才登记进本表，
#     并在下面写清「为什么修不掉」。
#
# 格式：每行 `<Target>:<pathComponents 用 . 连接>`；`#` 起头与空行忽略。
# ⚠️ 顺序无关（脚本按集合比对），但请按 target / 类型分组，方便 review 读 diff。
#
# ⚠️ **扫描范围 = 各 target 的主 symbols 文件（`<Target>.symbols.json`）
#   + 本包内跨 target 的扩展块文件（`<Target>@<本包另一个 target>.symbols.json`）。**
#   只有 `<Target>@<第三方模块>.symbols.json`（声明在 SwiftUI 自家类型上的
#   `extension Color` / `extension Transition` / `extension ButtonStyle` 成员）
#   **不在射程内**——代价逐字登记在脚本头注释《范围定案与代价》一节，先读那节再改这里。

# --- OhMyDesign ---
# 函数体取 `Color("shadow-…", bundle: .module)`，而 `Bundle.module` 访问器由 SwiftPM
# 生成在本 target 内、随 `defaultIsolation` 成为 MainActor 隔离（#290 实测）。
# ⚠️ 这条理由只说了一半。给它加 `nonisolated` 的**完整**编译错误是 5 种（8 行，本轮实测）：
#   · `error: call to main actor-isolated initializer 'init(color:radius:x:y:)'
#     in a synchronous nonisolated context` —— **头一条**，出现 4 次（4 个 case 各一次）。
#     根因是 `CoreElevation.Spec` **自己**在 `.defaultIsolation(MainActor.self)` 下就是
#     MainActor 隔离的，跟 shadow 色无关；
#   · 另外 4 条才是 `shadowNoneColor` / `shadowSmallColor` / `shadowMediumColor` /
#     `shadowLargeColor` 各一条 `main actor-isolated static property … can not be
#     referenced from a nonisolated context`。
#   ⇒ 想解开这条豁免，光把 shadow 色挪出去不够，还得先让 `Spec` 本身 nonisolated。
OhMyDesign:CoreElevation.spec(for:)

# --- OhMyDesignShaders ---
# 函数体走 `device.makeDefaultLibrary(bundle: .module)`，而 `Bundle.module` 访问器由
# SwiftPM 生成在本 target 内、随 `defaultIsolation` 成为 MainActor 隔离；标
# `nonisolated` 会编译失败：`main actor-isolated static property 'module' can not be
# referenced from a nonisolated context`（源码注释实测）。加载检查是诊断 / 测试用 API，
# MainActor 对它没有实际约束。
OhMyDesignShaders:OhMyDesignShaders.assertShaderLibraryLoadable(functions:)
