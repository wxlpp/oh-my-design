# Task: 字段校验基础层 + FormField

## Description

新增 `FieldValidation` / `FieldRequirement` 枚举、对应 `@Entry` 环境值与 `View.fieldValidation(_:)` / `View.fieldRequirement(_:)`，以及 `FormField` 容器（label + 必填星号、description、错误行）。

契约以 `.claude/prds/heroui-absorption.md` 的 FR-1 为准。

## Acceptance Criteria

- [ ] `FormField` 内放系统 `TextField`：invalid 时 label 与错误行显示 danger 色，设回 valid 错误行淡出
- [ ] `.fieldRequirement(.required)` 显示星号，可访问 label 追加「必填」
- [ ] 播报规则：仅 valid→invalid 或错误文本变化时播报一次；首次渲染 invalid 与值未变的重建不播报（有测试）
- [ ] description 文本经环境值下传；新增公开 `View.fieldAccessibilityHint()` 供系统控件挂到真实输入节点（#374 的自有控件内部也走它）
- [ ] `FormField` 进 `components[]` 并附公约判定记录

## Technical Details

按 PRD FR-1 的无障碍契约：label 用 `accessibilityLabeledPair` 关联；容器不挂 hint。实现前先确认 `accessibilityLabeledPair` 在 iOS 26 / macOS 26 的可用性，不可用则在 spec 里改定并同步 PRD。视觉优先级 disabled > invalid > focused。
