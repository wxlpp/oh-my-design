# Task: TagGroup

## Description

基于 `Tag` + `FlowLayout` 的可选标签组，`selectionMode` 枚举、`Binding<Set<ID>>`、禁用集合，选中色从环境 `coreAccent` 派生。

契约以 `.claude/prds/heroui-absorption.md` 的 FR-9 为准。

## Acceptance Criteria

- [ ] 基数只计数据内 ID、未知 ID 永不增删；single 点已选 = 取消、点未选 = 替换数据内已选集合；外部写入多个数据内 ID 照样渲染、下次点选归一
- [ ] 切换 mode 不改写绑定；禁用项不可切换但可显示已选；未知 ID 保留
- [ ] 每个标签是带 `.isSelected` trait 的按钮，键盘可聚焦；本轮无删除
- [ ] 选中底色与描边随自定义 `coreAccent` 变化（测试）
- [ ] 进 `components[]` 并附公约判定记录

## Technical Details

选中色派生复用 `CoreAccentEnvironment.swift` 里既有的 accent 衍生函数；没有合适的就在那里补，不在组件里写公式。
