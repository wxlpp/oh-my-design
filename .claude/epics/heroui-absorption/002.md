# Task: 5 个控件接入校验态 + SearchField 修复

- [ ] 5 个控件 invalid 时描边 / 图标取 danger 语义 token（iOS 腿可见）
- [ ] 错误原因与 description 挂在真实输入节点：PinCode 为逐格节点，TagInput 为输入框而非删除按钮
