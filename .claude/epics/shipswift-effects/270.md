# Task: 收口组件登记表扫描根

## 问题

`ComponentRegistryGuard.coreDesignSources` 至今仍是**单根** `Sources/CoreDesign` ⇒ 两个新 target 里的 public 类型对组件登记表**结构上不可见**。#246 交付的扩展成员扫描器只覆盖 `extension` 上的**静态成员/方法**（`entryPoints`），**不覆盖 public 类型本身**（`components`）。

⇒ 每落一个新组件就多欠一笔，且**没有任何判据会红**——这正是 G-7 记在案的失效形态。

## 已欠的账（截至本 issue 创建）

`epic/shipswift-effects` 上 **5 个**：

| 类型 | 来自 | 位置 |
|---|---|---|
| `Shine<Content: View>` | #250 | `Sources/CoreDesignEffects/Shine.swift` |
| `RadarChart` / `RingChart` / `ActivityHeatmap` / `NetworkGraph` | #255 | `Sources/CoreDesignCharts/` |

PR #269（#252）合入后再 **+3**：`ScanningOverlay` / `GlowSweep` / `LightSweep` ⇒ 共 **8 个**。

三个 task 各自的处置都是「不进 `components`，因为塞进去会被判成幽灵条目」——**这个理由在单根前提下成立**，但它把问题一路推给了下一个人。

## 归属：AD-4 把它挂给了 #255，而 #255 没做

`docs/component-contract.md` 的 AD-4《下游连锁一》把「Charts 走 b 会触发整条 J-2 链」记在案，实际处置挂在 #255。#255 交付时未扩扫描根 ⇒ 该连锁**从未被执行**。本 issue 是把它显式接过来。

## ⚠️ 这不是「改一行扫描根」——它会顶动一整条判据链

AD-4《下游连锁一》逐字列明：

- `step1/2 ⇒ semantic`（`ComponentRegistryGuard`）⇒ **硬断言** `needsExtensionPoint` ⇒ 进 J-2 定义域
- ⇒ `ComponentExtensionPointGuard` 的 `inspected.count == 11` **变 15 ⇒ 红**
- ⇒ `missing.isEmpty` 要求**同批交出真实扩展点**，而该文件逐字**禁止**「为了让它变绿把新条目塞回 `knownMissingExtensionPoints`」
- ⚠️ 被顶动的不止 `== 47` / `== 31`，还有 `ComponentTextParamGuard` 的 `covered.count == 30`、`localizedByType.count == 11`、`carrying.count == 9`，以及 `unmappedOwners` / `functionSideBareText` 两个**固定集合**
- ⚠️ AD-4 明写：「若落形态 C（不给扩展点）须在 notes 写明理由」这条出路对 `semantic` 条目**机械上不可能**——schema 硬断言 + J-2 定义域都不允许；形态 C 只对落 `prescriptive` 的条目成立

⇒ 落地前必须先想清楚 **8 个类型各自的判定法归属**，以及**哪些需要真实扩展点**。不要先改扫描根再对着一屏红去凑。

## Acceptance Criteria

- [ ] `ComponentRegistryGuard` 的扫描根由单根改为多根，复用 `#246` 的 `GuardScanRoots`（**不要另起一套根列表**——两套根必然漂）
- [ ] 8 个 public 类型逐个走判定法，登记进 `docs/component-registry.json` 的 `components`
- [ ] **需要真实扩展点的条目同批交出扩展点**，不得塞 `knownMissingExtensionPoints`
- [ ] 被顶动的计数逐个更新到新值，且**每个新值都有出处**（不是把断言改成通过为止）：`ComponentExtensionPointGuard` 的 `inspected.count`、`ComponentRegistryGuard` 的 47 / 25、`ComponentTextParamGuard` 的 31 / 30 / 11 / 9 与两个固定集合
- [ ] **不放松任何既有判据**——数值变化必须是定义域扩大的自然结果，逐条说明
- [ ] `#250` / `#255` / `#252` 三处「不进 components」的说明同步改写，注明已由本 task 收口
- [ ] 变异实证：新增一个未登记的 public 类型 ⇒ 判红；补登记 ⇒ 转绿
