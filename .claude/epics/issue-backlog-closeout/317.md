# 任务：#317 macOS 位图逐字节判据偶发差 1 LSB

规格见 issue 正文 + 两条评论（累计 15 跑 4 红；最近一次完整证据：`TextAndDisplayTests`
`endpointRenderIsIndependentOfTheHiddenLayer`，3/80000 字节不同、每处差 1 个 LSB）。

## 待办（issue 列的三条，按序）

1. **先查确定性**：`expectBitmapsEqual` 走的离屏渲染路径在 macOS 上是否本就不保证
   逐字节确定（注意 issue 里那条线索：「看起来像离屏渲染的舍入 / 光栅化不确定性」——
   但**不预设结论**，用实验说话：同一进程内重复渲染同一位图、跨进程、跨 run，量化差异分布）。
2. 按查到的机理选判据形态：容差比较 / 感知比较 / 换钉等价性质（如「差异像素数有界」
   「每处差 ≤ 1 LSB 且 ≤ N 处」——注意别把偶发噪声的现值钉成阈值，那是给 bug 发绿灯）。
3. 取样量提到可分辨量级（现有 ≈0.23 红率的置信区间太宽），证明修复后红率收敛。

## 已知坑

- 位图尺寸随行号漂移变过（160000 → 80000 B），别按行号引测试。
- 判据改造后要**变异实证**（构造一个真实会红的逻辑错，证明新判据仍抓得到）——
  容差化最常见的病是「连真错也放过去」。
- macOS `swift test` 全量跑一遍 ≈ 85s；取样跑数按 issue 的统计口径记账。
