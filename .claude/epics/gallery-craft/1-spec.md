# Gallery 材质与内容组合设计

用户已确认先做三个方向：材质对照、带说明选项卡、卡片组合样例。此批只交付 OhMyDesign 与预览宿主，不更新 OhMyStory 依赖或修改其首页、AI chat bar。

## 设计
- 材质对照：同一信息结构在安静/彩色背景上比较实底内容、既有 floatingGlass、主题色玻璃按钮；有浅/深模式。原组件默认参数不改变，不将内容卡片统一改成玻璃。
- 新增 SelectionCard<Value, Label>：单选卡片单元，以 value 与 Binding<Value> 表达选择，label 为调用方 ViewBuilder；调用方组合自适应网格。内部原生 Button、44pt 最小命中、选中边框/浅强调底色与固定槽勾号、禁用跟随环境。内容可换行、保持自然高度，不固定文本行数。选中仅淡变，复用 coreAnimation，无循环动效。布局与业务选择存储不由卡片负责。
- Gallery 三张示例选项为「灵感／专注／夜读」，每项图标、标题和短说明；提供禁用与大字检查。仅演示选择，不宣称修改应用阅读模式。
- 卡片组合：故事封面+最近章节、人物摘要、创作进度。数据均明确为示例，不联网、不生成图像。复用 Card、ProgressBar 与语义 token；氛围色只限装饰区，正文区域保持高对比。
- Gallery 入口可实际导航，自动截图可直接按 id 启动；窄屏单列、宽屏自适应，深浅模式均可检查。

## 边界与取舍
先做原生可操作样例而非修改整套材质基础；不新增播放器、天气控件、Toast 堆叠或持续动画。SelectionCard 无独立自有 style 协议；作为规定性卡片选择单元，与原生 Button 组合，label 槽承载内容变化。系统 Picker 菜单/列表与 RadioGroup 行式指示器继续分别使用。

## 验证
构建库和 iOS Gallery；验证选择互斥、重复选择无额外状态变化、禁用不改值；截图检查浅/深、320pt及大字换行、减弱动态效果。保留实际未验证范围，截图不声称物理触感或 VoiceOver 真机验收。新增组件登记表、README与文档同步。
